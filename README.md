# 🐻 Urso & o Amuleto

Um jogo de arcade onde **Bartolomeu, o urso**, recupera os **4 pedaços do Amuleto Dourado** — um em cada fase. Ao completar todos os desafios, o amuleto é reconstruído!

## Como jogar

Abra o arquivo `index.html` em qualquer navegador (desktop ou celular). Não precisa instalar nada.

```
# opcional: servir localmente
python3 -m http.server
# depois acesse http://localhost:8000
```

## As 4 fases

| Fase | Cenário | Desafio | Controles |
|------|---------|---------|-----------|
| 1 | 🌲 A Floresta | Colete 8 potes de mel e fuja das abelhas | Setas / arrastar |
| 2 | 🌊 O Rio | Pule de pedra em pedra para atravessar | Toque / Espaço / ↑ |
| 3 | 🕳️ A Caverna | Memorize e repita a sequência dos cristais | Toque nos cristais |
| 4 | ⛰️ A Montanha | Desvie das rochas por 20 segundos | Setas ← → / arrastar |

A cada fase vencida você ganha **um pedaço do amuleto** (mostrado no topo). Junte os 4 para vencer o jogo. 🏅

## Tecnologia

100% feito com **HTML + Canvas + JavaScript** em um único arquivo, sem dependências.
